Problem

Everyday Malaysian financial calculations are spread across different websites, documents, and technical rules.

People comparing a home loan, estimating tax, or planning EPF savings need a fast answer before they need professional advice. Many existing tools are cluttered, opaque about assumptions, or ask for personal details.

Solution

I designed one consistent, no-sign-up toolbox for seven frequent decisions.

One task per page

Each calculator presents only the inputs needed for that decision, followed by a readable breakdown.

Local-first calculation

Inputs and results stay in the browser. There is no account, database, or analytics dependency.

Malaysia-specific context

RM formatting, local terminology, progressive brackets, and official-source links make the tools easier to understand.

My role

I took the suite from opportunity to deployed product.

I defined the calculator scope, designed the interfaces, implemented the calculation logic and responsive frontend, wrote the explanatory and SEO copy, added verification notes, and deployed the site through GitHub and Vercel.

Decisions

A small stack was a product decision, not an absence of engineering.

Vanilla JavaScript

Each page loads quickly, works on basic hosting, and keeps the formulas visible and maintainable.

No backend

The calculators do not need to transmit financial inputs, reducing privacy and infrastructure risk.

Progressive disclosure

Advanced fields and detailed breakdowns appear only when useful, keeping the first interaction approachable.

What changed

7

live tools now share one product language and one privacy-first model. The second iteration added official source links, update dates, worked examples, and clearer limitations after a trust review.

What I learned

Financial UX is not only about getting a formula to run. Users need to see the assumptions, source, date, and calculation breakdown before they can decide how much confidence to place in a result.

Next

The roadmap focuses on evidence and feedback rather than adding features for their own sake.

Verification

Add automated test fixtures for official worked examples and version the rule sets by year.

Access

Add Malay and Chinese interfaces and improve keyboard and screen-reader testing.

Utility

Offer printable result summaries and a lightweight feedback channel.
