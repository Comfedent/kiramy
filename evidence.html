Product Evidence

Each project has a different maturity level. The page separates live functionality from planned validation so the portfolio does not overclaim traction.

Live / Educational

KiraMY

What works nowSeven Malaysia-focused calculators, local browser calculation, result breakdowns, next-step modules, official-source links and rule metadata for migrated tools.

Not proven yetNot yet measured: repeat use, user trust, commercial conversion, partner demand or rule accuracy across every edge case.

Next validation stepExpand rule versioning and test fixtures, then add a privacy-friendly feedback loop for calculation mismatches and missing scenarios.

Live / Local-first

Shiye Notes

What works nowCreate, edit, search, pin and delete notes; automatic LocalStorage saving; malformed data recovery; JSON import/export and backup reminders.

Not proven yetNot yet measured: long-term retention, backup behaviour, cross-device need or whether users trust browser-only storage.

Next validation stepTest export/import comprehension with users and explore optional client-side encryption for sensitive notes.

Engineering Evidence

The strongest engineering signal in this portfolio is not framework complexity; it is visible constraints, testable logic and a clear path for reliability work.

Tests available

Node built-in tests cover Shiye note-store logic, LocalStorage import/export behaviour, KiraStart plan-store handling and calculator rule examples.

  • Malformed note data recovery
  • JSON import validation
  • Merge import does not delete existing notes
  • Income tax, home loan, EPF and car loan calculation fixtures
Calculator logic

Income tax and home-loan pages now consume shared rule and calculator modules. EPF and car-loan pure calculation modules exist for tests; remaining pages are planned migrations.

LocalStorage recovery

Shiye Notes and KiraStart MY handle malformed stored data without crashing. Both projects now explain browser-only storage and provide JSON portability.

Responsive QA

Browser smoke tests were run across key English and Chinese pages with mobile viewports and no horizontal overflow in the tested flows.

Accessibility notes

Core pages use semantic sections, visible button labels, status text and keyboard-friendly controls where applicable. Further screen-reader testing remains planned validation.

Sources / update dates

KiraMY calculator pages expose official sources and review/update dates. Migrated rules include ruleVersion, effectiveYear, sourceName, sourceUrl, lastUpdated, assumptions and knownLimitations.

Current limitation: not every calculator page has completed DOM-to-module migration yet. That is tracked as planned reliability work rather than hidden.

Commercial Evidence

Commercial proof is separated from product polish. Where data does not exist, the page says so plainly.

KiraMY

Educational calculator suite with a future feedback loop, SEO content loop and optional rule-update subscription. User volume, conversion and revenue are not yet measured.

Shiye Notes

Local-first writing tool with portability improvements. Commercial demand is not yet measured; the next proof is whether users value browser-only privacy enough to use backups.

KiraStart MY

Guided planner for first-year money decisions. Future proof should come from scenario comparison usage, exported plans and user feedback on recommendations.

Bukit Pala

Pre-order validation plan for a local gift-set concept. Supplier and buyer research are still needed before pricing, payment or inventory.
