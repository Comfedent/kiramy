# KiraStart MY

A privacy-first first-year financial planner for Malaysian students, interns and fresh graduates.

## Run locally

No installation or build step is required. Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Included in the MVP

- Landing page with Malaysia-first positioning
- Three-step salary, living-cost and goals planner
- Simplified EPF, SOCSO, EIS and resident income-tax estimates
- Monthly cash-flow breakdown and plan-health score
- Contextual recommendations and 36-month milestone timeline
- Local-only draft saving via `localStorage`
- Responsive desktop and mobile layout

## Important calculation note

The tool is for planning education, not financial or tax advice. Statutory deductions are simplified estimates. The interface links to KWSP, PERKESO, LHDN and PTPTN so users can confirm current rules and their own circumstances.
